# 아하 속도 계산기

[계산기 열기](https://pasame.github.io/APA-SPEED-CALCUATOR/)

파티를 고르고 마을 SPD와 돌파·전광·재련을 입력하세요. 행동 순서는 기본 화면에서 확인합니다. 장비 구성과 조건부 효과는 캐릭터의 ‘장비·효과’에서 조정합니다.

‘고급 계산’에는 5종 목표 역산, 조건부 ON/OFF 비교, 예시 설정과 공유 링크가 있습니다. 설정은 두 모드별로 자동 저장되며 현재 모드 초기화는 다른 모드를 유지합니다. 잘못된 입력 중에는 마지막 유효 설정을 저장합니다.

‘4.7 찌라시’는 별도 상태로 계산하며, 아하 보유·편성·전광과 베타 장신구를 지원합니다. 비공식 자료이며 출시 전 변경 가능합니다. 미편성 기초항과 전광 참조에는 실기 미검증 가정이 있습니다.

실제 소수점 SPD를 모르면 역산은 추정입니다. 자연 행동 역산은 표시 단위 0.01 SPD, 상한 1000이며 보너스 턴을 자연 횟수에 포함하지 않습니다. 오프라인에서는 [index.html](index.html) 하나를 저장해 브라우저로 열면 됩니다. 브라우저 저장이 막힌 환경에서는 공유 주소를 사용할 수 있습니다.
