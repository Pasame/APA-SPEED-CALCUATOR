# 아하 속도 계산기

[**계산기 열기**](https://pasame.github.io/APA-SPEED-CALCUATOR/)

1. 파티를 고르고 **마을 SPD**를 입력하세요.
2. 돌파·전무·재련을 선택하세요.
3. 행동 순서는 기본 화면에서 바로 확인합니다. 찌라시의 아하 보유 버튼은 편성·전광 설정과 연동되며, 아하를 빼면 이전 보유 선택으로 돌아옵니다. 역산은 **세부**, 베타 계산은 **4.7 아하 찌라시**를 누르세요.

마을 SPD는 소수점까지 입력하세요. 찌라시 수치는 출시 전 바뀔 수 있습니다.

오프라인에서는 [index.html](index.html)을 저장해 브라우저로 열면 됩니다.
